Cómo ayuda IRIS

Un entorno seguro para aprender, detectar y actuar antes de que las señales escalen.

Simula

Practica escenarios conversacionales generados por IA, diseñados para imitar situaciones reales de manipulación emocional de forma segura y privada.

Detecta

El sistema analiza conversaciones en tiempo real para señalar red flags y comportamientos tóxicos, ayudándote a reconocer señales de riesgo.

Entrena

Desarrolla habilidades de asertividad y aprende a establecer límites saludables mediante retroalimentación constructiva tras cada simulación.
